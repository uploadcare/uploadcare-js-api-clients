Build and parse CDN URLs for transformations, groups, proxy and conversion paths. Atomic and tree-shakeable.

Getting started
API Reference

  • Round-trip parser

    Lenient parsing of any CDN URL flavor, including files, groups, nth elements, conversion results and proxified sources. Unknown operations survive serialization.

  • Typed operations

    48 operation creators with eager validation of ranges, enums and grammars, straight from the CDN docs.

  • Chain validation

    Cross-operation diagnostics for the core operation requirement, must-be-last rules, last-wins duplicates and dimension ceilings.

  • Tree-shakeable

    Twelve atomic entry points; import only what you use. The proxy entry is under half a kilobyte gzipped.
