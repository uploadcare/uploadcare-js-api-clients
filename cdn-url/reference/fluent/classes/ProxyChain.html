updateOperations() ​

ts
updateOperations(update): this;

Defined in: fluent/chain-base.ts:89

The primitive the other operation mutators are sugar over: rewrites the whole chain through a callback, preserving the chain subtype. Mirrors CdnUrl.updateOperations, and is the only way to edit by position — replacing the nth stackable operation, inserting at an index, or reordering. It is also the sole edit path for conversion chains (video/document/gif2video), which cannot be re-parsed from output.

The callback receives a defensive copy; whatever it returns becomes the new chain.

Parameters ​

ParameterType
update(current) => readonly CdnOperation[]

Returns ​

this

Example ​

ts
cdn.video(uuid).size({ width: 720 }).thumbs(5)
  .updateOperations((ops) =>
    ops.map((op) => (op.name === 'size' ? size({ width: 480 }) : op))
  ).path // → /uuid/video/-/size/480x/-/thumbs~5/
